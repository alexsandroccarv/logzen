Histórico de versão

Versão atual: —

Numeração MAIOR.MENOR.PATCH: o PATCH (3º número) é incrementado automaticamente a cada merge na main, documentando as issues fechadas; mudanças no MAIOR (1º) e no MENOR (2º) são solicitadas explicitamente (marcos do projeto). Também mantido em CHANGELOG.md e nos Releases.

v0.0.17 06/09/2026

  • Livros: campos "Formato" (Analógico/Digital) e "Posse" (Próprio/Emprestado) ao registrar ou editar um livro — issue #29.

v0.0.16 06/09/2026

  • Livros: botão "Editar" em cada registro, reabrindo o formulário preenchido com os dados atuais — salvar atualiza o mesmo registro, sem criar um duplicado — issue #28.

v0.0.15 06/09/2026

  • Livros: chave opcional da Google Books API em Configurações → Livros (evita a cota anônima, compartilhada por IP/rede), e mensagem específica quando a cota é esgotada — issue #27.

v0.0.14 06/09/2026

  • Versão inicial começa sem nenhuma categoria/item ativado — as 5 categorias que vinham sempre ativas viraram sugestões, ativadas só pelo usuário — issue #26.
  • Livros: mensagem clara quando Google Books e Open Library falham as duas (em vez de só repetir o erro da segunda), sugerindo o registro manual — issue #25.

v0.0.13 06/09/2026

  • Livros: Google Books passa a ser a fonte principal de busca (Open Library como segunda fonte), e a busca aceita ISBN além de título — issue #25.

v0.0.12 06/09/2026

  • Itens rastreados: novo tipo "Horário" (início e fim) — issue #23.
  • Livros: Google Books API como segunda fonte de busca, usada automaticamente quando a Open Library não encontra o título — issue #24.

v0.0.11 06/09/2026

  • Nova aba "Podcasts": assinaturas via iTunes Search API e episódios ouvidos, com avaliação pessoal e histórico preservado ao remover uma assinatura — issue #22.
  • Backlog: campo "Projeto" vira seletor dos projetos já usados (com opção de criar um novo), e a lista de tarefas passa a ser agrupada por projeto.

v0.0.10 06/09/2026

  • Entregas: corrige "Invalid Date" em cards com data corrompida e adiciona o checkbox "Não entregue" ao lado de "Entregue" — issue #19.
  • Nova aba "Backlog" alimentando "Objetivos do dia" via botão "Enviar para hoje", e limite rígido de 10 objetivos por dia (regra 1-3-5), respeitado também pela migração automática — issue #20.
  • Filmes: colar um link do YouTube na busca traz os dados do vídeo (título, miniatura, canal) via oEmbed, sem precisar de chave — issue #21.

v0.0.9 06/09/2026

  • Entregas: campo "Entregue" (checkbox + data) que move o registro para uma seção "Arquivo" recolhível, com opção de desfazer — issue #16.
  • Editar um registro já cadastrado em Entregas e em Filmes/séries, sem precisar remover e recriar — issue #17.
  • Filmes: tipos Show e Palestra no cadastro manual, e YouTube em "Onde assistiu" — issue #18.

v0.0.8 06/09/2026

  • Nova aba "Livros": registro de leitura com capa, autor, editora, idioma e páginas via Open Library API (gratuita, sem chave), com data de início/fim da leitura e avaliação pessoal (estrelas + opinião) — issue #14.
  • Nova aba "Entregas": cadastro de compras aguardando entrega (nome, data da compra, previsão, loja/e-commerce, rastreio e observações), com destaque para previsões vencidas — issue #15.

v0.0.7 06/09/2026

  • Objetivos do dia: regra 1-3-5 com cores por posição, arrastar para reordenar, migração automática de pendências para o dia seguinte e nota por objetivo — issue #12.
  • Filmes: registro de séries passa a ser por episódio (temporada, episódio e título opcional); filmes e séries ganharam o campo "Onde assistiu" (TV aberta, Cinema ou Streaming, com o serviço quando for o caso) — issue #13.

v0.0.6 06/09/2026

  • Categorias sugeridas e seção "Adicionar categoria" em Configurações — issue #10.
  • Nova aba "Filmes": registro de filmes/séries assistidos com busca via OMDb API (pôster, duração, prêmios) e avaliação pessoal (estrelas + opinião) — issue #11.

v0.0.5 06/09/2026

  • Todo item passa a ser editável/excluível em "Itens rastreados" — a etiqueta "Padrão" e a restrição de somente leitura saíram; excluir ou editar um item de fábrica continua sem apagar o histórico já salvo — issue #8.
  • Objetivos do dia (tasklist) no início da tela "Hoje"; "Nota do dia" virou "Como foi meu dia" e foi para o final — issue #9.

v0.0.4 06/09/2026

  • Gestão de itens (adicionar/editar/excluir) movida da tela "Hoje" para a seção "Itens rastreados" em Configurações; excluir ou renomear um item nunca apaga o histórico já salvo — issue #6.
  • Reordenar categorias e itens por arrastar e soltar, em Configurações — issue #7.

v0.0.3 05/09/2026

  • Rebranding para LogZen e tela "Hoje": registro diário de hábitos por categoria (Exercícios, Vícios, Hábitos, Ânimo/Saúde mental, Atividade sexual), com dados 100% locais e exportação/importação em JSON — issue #1.
  • Itens customizados por categoria (nome + tipo de input) e nota curta opcional no lançamento diário — issue #2.
  • Nota curta por item, fechada por padrão (ícone de lápis) — issue #3.
  • Exportar/importar dados movido para Configurações — issue #4.
  • Navegação entre dias na tela "Hoje" (setas anterior/próximo) — issue #5.

v0.0.2 05/09/2026

  • Primeiro incremento automático de versão (ajuste inicial do template/CI, sem mudança de funcionalidade visível).
